## II. A sharper statement of WHY (K) is hard

Today's decomposition says the machine-specific content of a template closure is exactly **a finite
set of word identities on the marker combs**.  For a carry-transparent machine those identities
exist because base-2 positional bookkeeping has no carries — every identity is a re-association.

For a `(K)` machine the analogous object would be a **finite identity set for base-3/2 digit
words**.  That is precisely what Mahler / AEV Conj 1.6 says does not exist.

> **(K) is blocked at the WORD-ALGEBRA layer, not the transport layer.**

This is a sharper localisation than "the wall is equidistribution".  It predicts — correctly — that
no improvement in transport machinery helps, which is exactly what the 11 no-go layers found one at
a time.  It also explains today's over-provisioning finding: in base 2 you can bound the head's
reach a priori (hence pads that over-provision by a clean `2^k`); in base 3/2 you cannot.

Four cheap, purely-measurable conditions.  Each is one simulator run; together they say whether the
x2 template can port to a machine, BEFORE investing a session.

1. **Transparency.**  Epoch multiplier is a power of the tape base ⟹ carry-chain length ≡ 0

2. **Frontier regularity.**  Milestone right-frontier advance is a clean power of the base.

   *(This one is new — it came out of today's over-provisioning measurement, and it is the cheapest
   discriminator we have: one run, no reverse-engineering.)*
3. **Frame periodicity match.**  The milestone frame's repetition unit = the tail-fold's repetition
   unit (the `uUnits_frameZ` analogue).  Read off the milestone tapes.
4. **Seam-on-the-nose.**  The low phase's OUT tape is the doubling phase's IN tape with a free
   tail.  Today this held with NO massaging at all on both parities (`hlowOdd_core'`,
   `hlowEven_core'`) — that is the signature of a genuine template machine.
