### 1.5 Method invariants — non-negotiable, each learned by being burned

1. **Identify sub-calls by TRANSPORT, never by length.** Only 4/8 `REGEN(7)`-length windows are
   genuine; a false positive inflated `REGEN(10)`'s apparent arity 15→16 and would have falsely
   refuted `exitArity 10 = 15` ✓. The exit-tree groundings (`exitSteps_tree_5/6/7/8`,
   `exitArity_grounds`) SURVIVE transport re-extraction — only the method was fragile.
2. **The correct test is exact and cheap.** Every transition is a total function of
   `(state,bit)`, so the `(st,h)` word over a window *determines* the whole trace ✓. Word
   identity is not a proxy for the trace test — it is equivalent, and it is a substring search.
3. **Canonicity from the definition, not from "earliest."** For k=7 the 8 windows split 4/4;
   "earliest" is a coin flip there. Ground it on the block `1^{2^k−3}` read off the tape.
4. **Never trust the build exit code or `head -n`.** The wrapper has reported exit 0 for a build
   whose log said `EXIT=1`, with `sorryAx` leaked into two theorems. Grep the FULL log for
   `error|warning|sorry|failed|EXIT=1`; a real build's log is ~276 lines (it prints every
   `#print axioms`); `#print axioms` every new theorem.
5. **Derive tape extent FROM the tape** (`min/max` of the cells), never from caller-maintained
   `lo`/`hi`. That bug produced a half-tape "decisive probe" and five probes shared it.
6. **Formalization must match its prose.** Seven defects of this class were fixed on
   2026-07-17. If you name something a law / closure / `∀`, make it be one.
7. **a=5 AND a=6 both live in `build(2)`.** Generations run on in ONE orbit.
8. **No Mathlib** in `X2.lean`: no `ring`/`norm_num`. Symbolic `p` makes `whnf` exponential in
   chain depth — chunk long kernel runs.
